## Project Overview

The **AI Emergency Response System** is a web-based platform designed to provide quick assistance during emergency situations.  
The system uses AI-based voice detection to identify distress keywords such as **"help"** or **"emergency"**, and then triggers a response that can notify emergency contacts or guide users to nearby medical assistance.

The application provides:
- Emergency voice detection
- Quick access to hospitals
- First aid guidance
- Simple and responsive user interface

## Features

- **AI Voice Detection**
  - Detects emergency keywords like *help* or *emergency* using speech recognition.

- **Emergency Assistance**
  - Triggers alerts when distress words are detected.

- **Hospital Locator**
  - Displays hospitals for quick medical assistance.

- **First Aid Guide**
  - Provides quick first aid instructions during emergencies.

- **Responsive Interface**
  - Clean and user-friendly UI built using HTML and CSS.
